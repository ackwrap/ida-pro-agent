## 0.4.9

- Add a full-height right-side AI Chat dock with Agent-style roles and emojis, balanced message spacing, Markdown, syntax-highlighted code blocks, message/code copy controls, and bounded incremental rendering for streaming and long conversations. Keep original text in external chat history; move history writes off the UI thread.
- Add the per-model **Effort** selector and persist the selected reasoning strength. Add external per-binary analysis memory and evidence-based protection, function, and type-recovery workflows through `/memory` and `/workflow`; memory mutations retain the current conversation approval policy.
- Share compact response and evidence rules across ordinary and tool-enabled chat. Reserve complete workflow steps and project-file metadata within the 8 KiB system budget before adding complete memory records. Recover from unknown or unloaded tools without running their operations; later discovered writes still require the applicable approval.
- Read `AGENTS.md`, `Agents.md`, or `agents.md` once from the current IDB directory and cache the result, including a missing file. Reuse it across requests, conversations and compaction. `/instructions` shows status; `/instructions reload`, switching projects, or reopening the database reads changes. Complete UTF-8 files up to 32 KiB are retained as required model context; larger files use bounded file-tool reads. Current user instructions and operation permissions retain priority.
- Isolate Gateway client sessions and bound plugin streaming queues. Keep the 23-tool underscore-named MCP catalog and existing RPC contracts compatible with 0.4.8.

**Upgrade:** Close IDA, install the complete 0.4.9 package for your platform, then restart IDA and reconnect MCP clients. Existing provider settings and external chat history remain available. Stable AI UI support remains IDA Professional 9.4 / Qt 6.8.2; the Windows IDA 9.5 experimental path still requires strict ABI preflight and live acceptance.

- AI Chat 默认停靠为全高右侧栏，加入 Agent 样式的角色分层与 Emoji、适中的消息间距、Markdown、代码块语法高亮及消息/代码复制。流式输出和长会话渲染使用性能预算，外部历史保留原文，历史写入移到 UI 线程之外。
- 新增按模型保存的 **Effort** 推理强度选择器；通过 `/memory` 和 `/workflow` 提供独立于 IDB 的分析记忆及基于工具证据的保护强度、函数调查、类型恢复工作流，记忆修改沿用当前会话审批策略。
- 普通聊天与工具聊天共享简洁输出和证据规则。8 KiB 系统提示词预算先保留完整工作流和项目文件元数据，再添加完整记忆记录。未知或未加载工具不会执行操作，模型可以发现工具后重试；后续写入仍遵循审批策略。
- 首次在当前 IDB 所在目录检查 `AGENTS.md`、`Agents.md`、`agents.md` 并缓存，包括未找到文件的结果；后续请求、切换会话和上下文压缩复用缓存。`/instructions` 查看状态，`/instructions reload`、切换项目或重新打开数据库时读取变更。32 KiB 以内的完整 UTF-8 文件作为必要模型上下文保留，更大的文件使用分段文件工具读取；当前用户指令与操作权限仍保留优先级。
- 隔离 Gateway 客户端会话并限制插件流式队列；23 个下划线命名的 MCP 工具及既有 RPC 合同与 0.4.8 保持兼容。

**升级：** 关闭 IDA，安装对应平台的完整 0.4.9 发布包，再重启 IDA 并重连 MCP 客户端。现有供应商设置与外部聊天历史继续可用。稳定 AI UI 仍面向 IDA Professional 9.4 / Qt 6.8.2；Windows IDA 9.5 实验路径仍须通过严格 ABI 预检与实机验收。
