## 0.4.8

- Make OpenCode 2 the configuration manager's default OpenCode target. Label configuration actions **Install MCP** / **Update MCP** and document Scoop's `versions/opencode2` and npm's `@opencode/cli@2`; the launch command remains `opencode`.
- Write the native `mcp.servers.ida-mcp` format with `disabled: false`, `codemode: false`, `protocol: "legacy"`, and separate catalog/execution timeouts. Migrate only the old IDA entry while preserving other servers, settings, and JSONC comments. Removing IDA configuration clears both formats.
- Validate native enablement and timeout fields, and use supported global `opencode.jsonc` / `opencode.json` files instead of the obsolete `config.json` fallback.
- Update the OpenCode regression adapter for v2 permissions and standalone execution. Keep the 23-tool MCP catalog and existing RPC contracts compatible with 0.4.7.

**Upgrade:** Close IDA, install the complete 0.4.8 package, then restart IDA and reconnect MCP clients. For OpenCode 2, open `ida-mcp -web` and use **Update MCP**. If its background server is running, run `opencode reload`, then check the connection with `opencode mcp list`.

- 管理页默认支持 OpenCode 2，配置按钮明确为 **Install MCP** / **Update MCP**，补充 Scoop 的 `versions/opencode2` 和 npm 的 `@opencode/cli@2` 安装说明；启动命令仍为 `opencode`。
- 写入原生 `mcp.servers.ida-mcp` 格式，使用 `disabled: false`、`codemode: false`、`protocol: "legacy"` 和分别设置的目录读取、工具执行超时。只迁移旧的 IDA 条目，保留其他服务器、设置及 JSONC 注释；移除时清除两种格式中的 IDA 条目。
- 校验新版启用字段和超时格式，选择受支持的全局 `opencode.jsonc` / `opencode.json`，移除过时的 `config.json` 回退。
- OpenCode 回归适配器使用 v2 权限格式和独立执行模式；23 个 MCP 工具及既有 RPC 合同与 0.4.7 保持兼容。

**升级：** 关闭 IDA、安装完整的 0.4.8 发布包，再重启 IDA 并重连 MCP 客户端。OpenCode 2 用户打开 `ida-mcp -web`，点击 **Update MCP**；若后台服务正在运行，执行 `opencode reload`，再用 `opencode mcp list` 检查连接。
