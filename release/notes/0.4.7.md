## 0.4.7

- Add automatic stable-release checks to the Qt plugin and local Web manager. Check the public `ackwrap/ida-pro-agent` releases at most once every 24 hours; compare numeric versions and ignore drafts and prereleases.
- Add **Check for Updates...** and **Software Updates** controls in IDA, plus the same controls in the Web manager: check manually, disable automatic checks, and open the matching release page. Manual checks have a one-minute cooldown. Download and installation remain manual.
- Share the automatic-check preference and release cache between both interfaces, outside the IDB and provider settings. Offline and rate-limit failures preserve previous release information. Requests contain the application version without database contents, chat history, or provider credentials; headless plugins and stdio/HTTP MCP processes do not run checks.
- Stabilize Linux/macOS streaming queue tests by observing the terminal event before draining the queue, preserving the byte and event limits without depending on a fixed startup delay.
- Keep the 23-tool MCP catalog and existing RPC contracts compatible with 0.4.6. The plugin's displayed version now comes from the same version file as the Gateway.

**Upgrade:** Close IDA, install the complete 0.4.7 package, then restart IDA and reconnect MCP clients. Existing providers and external chat history are retained. Set **Software Updates → Check for stable releases automatically (once a day)** off to disable background checks.

- Qt 插件和本地 Web 管理页新增正式版自动更新检测，每 24 小时最多查询一次公开仓库 `ackwrap/ida-pro-agent` 的 Release，按数字版本比较并忽略草稿和预发布版本。
- IDA 新增 **Check for Updates...** 和 **Software Updates** 控件，Web 管理页提供相同入口：手动检查、关闭自动检测、打开对应发布页面。手动检查间隔为一分钟，下载与安装仍由用户手动完成。
- 两个界面共享自动检测设置与版本缓存，保存在 IDB 和供应商配置之外。断网或限流时保留已有版本信息；检测请求不携带数据库、聊天历史或供应商凭据。无界面插件、stdio 和 HTTP MCP 进程不执行检测。
- Linux/macOS 流式队列测试改为确认终止事件后再读取队列，在继续验证字节数和事件数上限的同时，消除固定启动等待造成的误报。
- 23 个 MCP 工具及既有 RPC 合同与 0.4.6 保持兼容，插件显示版本与 Gateway 使用同一个版本文件。

**升级：** 关闭 IDA、安装完整的 0.4.7 发布包，再重启 IDA 并重连 MCP 客户端。现有供应商配置和外部聊天历史继续保留；关闭 **Software Updates → Check for stable releases automatically (once a day)** 可停用后台检测。
