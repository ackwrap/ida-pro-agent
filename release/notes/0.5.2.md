## 0.5.2

- Fix Claude tool calls that take no arguments. Tools such as `ida_database_info` and `ida_ui_cursor` previously ended the turn with a provider protocol error.
- Fix long OpenAI Responses turns failing as they completed. Single SSE event lines may now be as large as the event limit (up to 1 MiB) instead of 64 KiB.
- Stop running tool calls after **Cancel**, `/new` or `/clear` when the reply had already finished with tool calls but the stream had not yet closed.
- Keep the previous conversation when chat history is saved but not restored. A new conversation is now created instead of overwriting the most recently stored one.
- Retain the most recently updated conversations when pruning stored history, so the conversation you just used is not deleted.
- Stop truncating large disassembly or pseudocode selections sent to the AI Chat input at 32,767 characters.

**Upgrade:** Close IDA and IDAT, then install the matching plugin and Gateway from the same release package. Settings and chat history are kept. The stable AI UI still requires IDA Professional 9.4 / Qt 6.8.2.

- 修复无参数的 Claude 工具调用。`ida_database_info`、`ida_ui_cursor` 等工具此前会以供应商协议错误结束本轮对话。
- 修复较长的 OpenAI Responses 对话在完成时失败的问题。单行 SSE 事件现在可以达到事件上限（最大 1 MiB），不再限制为 64 KiB。
- 回复已以工具调用结束但流尚未关闭时，**Cancel**、`/new` 或 `/clear` 不再继续执行这些工具调用。
- 保存但不恢复聊天历史时保留之前的对话：现在会新建对话，而不是覆盖最近保存的对话。
- 清理历史时保留最近更新的对话，不再删除刚刚使用过的对话。
- 发送到 AI Chat 输入框的大段反汇编或伪代码不再在 32,767 个字符处被截断。

**升级：** 关闭 IDA 与 IDAT，然后从同一发布包安装对应版本的插件和 Gateway。设置与聊天历史会保留。稳定 AI UI 仍要求 IDA Professional 9.4 / Qt 6.8.2。
