## 0.5.6

- Fix blank Markdown tables and crashes when clicking or selecting table cells in AI Chat messages that also contain fenced code blocks.
- Apply code syntax highlighting after message insertion completes. This prevents an early layout refresh from leaving table coordinates incomplete, while preserving code colors and copying.
- Add Qt 6.8.2 regression coverage for tables before and after code blocks, mouse clicks and double-clicks, input-method cursor queries, history restoration, streamed reply completion, theme changes, resizing and message pruning.

**Upgrade:** Close every IDA and IDAT instance, then install the matching plugin and Gateway from the same release package. Settings, chat history and analysis memory are kept. The stable AI UI still requires IDA Professional 9.4 / Qt 6.8.2.

- 修复 AI Chat 同一条消息同时包含 Markdown 表格和代码块时，表格显示为空白，以及点击或选中单元格后崩溃的问题。
- 代码语法高亮改为在消息插入完成后执行，避免过早刷新布局导致表格坐标数据不完整，同时保留代码颜色和复制功能。
- 新增 Qt 6.8.2 回归测试，覆盖表格位于代码块之前或之后、点击和双击、输入法光标查询、历史恢复、流式回复完成、主题切换、窗口缩放和消息裁剪。

**升级：** 关闭所有 IDA 与 IDAT 实例，然后从同一发布包安装对应版本的插件和 Gateway。设置、聊天历史与分析记忆会保留。稳定 AI UI 仍要求 IDA Professional 9.4 / Qt 6.8.2。
