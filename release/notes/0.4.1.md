## Changes

- Accept IDA's suspended debugger state (`running=false`, `suspended=true`) in Gateway. This fixes `INTERNAL_ERROR` on `debugger.info` and debugger action results while the target is paused.
- Align protocol schemas and shared regression fixtures with IDA's execution-state flags.
- Clarify that `ui: false` describes unavailable MCP UI inspection/control tools, not IDA's graphical interface or permission dialogs.

## 更新内容

- 修复目标暂停时，Gateway 将 `running=false`、`suspended=true` 误判为内部错误的问题，覆盖 `debugger.info` 及调试操作结果。
- 同步协议约束与共享回归样例，明确运行和暂停状态。
- 说明 `ui: false` 表示未提供 MCP UI 检查与控制工具，不影响 IDA 图形界面和授权弹窗。
