## 0.5.0

- Add a Linux `.deb` package for **Ubuntu 24.04+ / Debian 13+ amd64**, alongside the portable tar.gz. APT installs system dependencies and exposes `/usr/bin/ida-mcp`, `idat-with-agent`, and `ida-agent-setup`.
- Add **IDA Agent** to the application menu with the shared product icon and matching window icon. The setup window supports English and Chinese, an IDA user-directory selector, **Install plugin**, **Remove plugin**, and **Open manager**.
- Install the plugin for the current user through a managed link. Existing manual plugins require explicit replacement and receive a backup. Package upgrades keep the link working; removal preserves provider settings and chat history. The manager launcher reuses its running instance and supports `ida-agent-setup --stop-manager`.
- Add **Ctrl+Shift+A** to open AI Chat and focus its input. Repeating it preserves the current conversation and draft. Customize **Open AI Chat** (`ida-agent:ai:open`) in IDA's shortcut settings.
- Validate Linux package installation, GUI launch, manager reuse, upgrade, plugin removal, and package purge on Ubuntu 24.04 and Debian 13 in the release workflow before publication. Windows and macOS installers remain available.

**Upgrade:** Close IDA and IDAT before installing the matching plugin and Gateway. On supported Linux systems, run `sudo apt install ./ida-agent-0.5.0-linux-x64.deb`, then open **IDA Agent** as your normal user and click **Install plugin**. Select your `IDAUSR` if customized; otherwise use `~/.idapro`. See the [Linux installation guide](https://github.com/ackwrap/ida-pro-agent/blob/v0.5.0/release/linux/INSTALL.md). The stable AI UI still requires IDA Professional 9.4 / Qt 6.8.2. IDA and Qt runtime libraries are supplied by your IDA installation.

- 新增 **Ubuntu 24.04+ / Debian 13+ amd64** 的 Linux `.deb` 安装包，同时保留 tar.gz 便携包。APT 自动安装系统依赖，并提供 `/usr/bin/ida-mcp`、`idat-with-agent` 和 `ida-agent-setup`。
- 应用菜单新增 **IDA Agent**，使用统一的项目图标与窗口图标。图形设置界面支持中英文、选择 IDA 用户目录、**安装插件**、**移除插件**和**打开管理页**。
- 使用受管理的链接为当前用户安装插件。替换手工安装的插件需要明确确认并保留备份；升级包后链接继续生效，移除时保留供应商设置与聊天历史。管理页启动器复用已运行的实例，并支持 `ida-agent-setup --stop-manager` 停止该实例。
- 新增 **Ctrl+Shift+A** 打开 AI Chat 并聚焦输入框；重复按下保留当前对话和草稿。可以在 IDA 快捷键设置中修改 **Open AI Chat**（`ida-agent:ai:open`）的按键。
- 发布工作流新增 Ubuntu 24.04 和 Debian 13 的实际安装、图形界面启动、管理页复用、升级、插件移除和卸载验证，通过后才发布；继续提供 Windows 与 macOS 安装包。

**升级：** 安装前关闭 IDA 与 IDAT，并一起更新对应版本的插件和 Gateway。支持的 Linux 系统运行 `sudo apt install ./ida-agent-0.5.0-linux-x64.deb`，再以普通用户打开 **IDA Agent** 并点击 **安装插件**。自定义用户目录时选择对应的 `IDAUSR`，默认目录是 `~/.idapro`。详见 [Linux 安装说明](https://github.com/ackwrap/ida-pro-agent/blob/v0.5.0/release/linux/INSTALL.md)。稳定 AI UI 仍要求 IDA Professional 9.4 / Qt 6.8.2，IDA 与 Qt 运行库由已有的 IDA 安装提供。
