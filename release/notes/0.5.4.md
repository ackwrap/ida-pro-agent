## 0.5.4

- Guard against an AI Chat crash after selecting a Markdown table and switching docked windows. Complete pending document layout before Qt queries selection geometry, including around message updates, while preserving the selection for copying.
- Add an optional Windows regression test against IDA's Qt 6.8.2 runtime, covering table selections, reply completion, history pruning, resizing and reparenting.

**Upgrade:** Close every IDA and IDAT instance, then install the matching plugin and Gateway from the same release package. Settings, chat history and analysis memory are kept. The stable AI UI still requires IDA Professional 9.4 / Qt 6.8.2.

- 为 AI Chat 选中 Markdown 表格后切换停靠窗口时的崩溃加入防护。在 Qt 查询选区位置前完成文档布局，并在消息更新前后处理相关布局，保留选区及复制功能。
- 新增使用 IDA 自带 Qt 6.8.2 的 Windows 可选回归测试，覆盖表格选区、回复完成、历史裁剪、缩放和父窗口切换。

**升级：** 关闭所有 IDA 与 IDAT 实例，然后从同一发布包安装对应版本的插件和 Gateway。设置、聊天历史与分析记忆会保留。稳定 AI UI 仍要求 IDA Professional 9.4 / Qt 6.8.2。
