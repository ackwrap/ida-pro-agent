## 0.5.3

- Fix a Linux and macOS issue where opening AI chat history or analysis memory could release SQLite locks held by other connections in the same IDA process. With several IDA instances sharing `chat.db` or `analysis-memory.db`, this could lose history writes or corrupt the database.
- Storage files are now validated without opening them. Symlinks, hard links, files owned by another user and files readable by others are still rejected. Windows is unchanged.

**Upgrade:** Close every IDA and IDAT instance, then install the matching plugin and Gateway from the same release package. Settings, chat history and analysis memory are kept. The stable AI UI still requires IDA Professional 9.4 / Qt 6.8.2.

- 修复 Linux 与 macOS 上的问题：打开 AI 聊天历史或分析记忆时，可能释放同一 IDA 进程中其他连接持有的 SQLite 锁。多个 IDA 实例共享 `chat.db` 或 `analysis-memory.db` 时，这可能导致历史写入丢失或数据库损坏。
- 现在无需打开存储文件即可完成校验。符号链接、硬链接、属于其他用户的文件以及其他用户可读的文件仍会被拒绝。Windows 不受影响。

**升级：** 关闭所有 IDA 与 IDAT 实例，然后从同一发布包安装对应版本的插件和 Gateway。设置、聊天历史与分析记忆会保留。稳定 AI UI 仍要求 IDA Professional 9.4 / Qt 6.8.2。
