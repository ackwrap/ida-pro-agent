## 0.4.6

- Fix Windows streamed chat failures that could surface as `WinHttpQueryDataAvailable` / `ERROR_WINHTTP_INCORRECT_HANDLE_STATE` (12019). Asynchronous waits keep requests alive across delayed headers and SSE frames, preserve incremental UTF-8 delivery, and honor cancellation, idle and overall deadlines.
- Save Windows external chat history even when a database's `.i64` has not yet been packed. The database history key stays consistent after packing; chat history remains outside the IDB.
- Merge PR #1: add pinned official Python MCP SDK regressions over stdio/HTTP, simulated RPC peers, wire-based evidence checks, and reproducible entry points for installed Codex, Claude Code and OpenCode clients. CI runs the SDK fixtures on Windows, Linux and macOS, including real Unix IPC on Linux/macOS. Add a queue wait-expiry test that verifies no admission slot leaks.
- Publish project-owned source under MIT in `ackwrap/ida-pro-agent`, with automatic source/documentation synchronization from the development repository. Third-party dependencies retain their own licenses.
- Keep the 23 underscore-named MCP tools and existing typed RPC contracts compatible with 0.4.5. The regression fixture executable is test-only and is excluded from release packages.

**Upgrade:** Close IDA, install the complete package, then restart IDA and reconnect MCP clients. SDK and simulated-backend results do not establish actual Agent/model compatibility or licensed IDA behavior; those require separately recorded runs.

- 修复 Windows 流式聊天可能出现的 `WinHttpQueryDataAvailable` / `ERROR_WINHTTP_INCORRECT_HANDLE_STATE`（12019）。异步等待使请求能跨越延迟响应头和 SSE 数据间隔，保留增量 UTF-8 输出，并正确响应取消、空闲期限和总期限。
- Windows 数据库 `.i64` 尚未打包时也能保存外部聊天历史；打包前后的历史键保持一致，聊天记录继续保存在 IDB 之外。
- 合并 PR #1：增加固定版本官方 Python MCP SDK 的 stdio/HTTP 回归、模拟 RPC 后端、基于实际协议流量的证据判定，以及已安装 Codex、Claude Code、OpenCode 的可复现测试入口。CI 覆盖 Windows、Linux、macOS，Linux/macOS 另验证真实 Unix IPC；增加队列等待到期且执行槽不泄漏的测试。
- 项目自有源码以 MIT 许可证公开到 `ackwrap/ida-pro-agent`，开发仓库的源码与文档由 GitHub 自动同步；第三方依赖保留各自许可证。
- 与 0.4.5 保持相同的 23 个下划线 MCP 工具和 typed RPC 合同；模拟回归程序仅用于测试，不进入发布包。

**升级：** 关闭 IDA、安装完整发布包，再重启 IDA 并重连 MCP 客户端。SDK 与模拟后端结果不能代替真实 Agent/模型兼容性或需要许可的 IDA 联调，后者需单独记录证据。
