## Changes

- Rename the Gateway executable, source module, MCP server, and client entry to `ida-mcp`; keep the plugin and package named `ida-agent`.
- Require a fresh installation of the complete package. No old-name aliases or automatic MCP configuration migration are provided.
- Ask for debugger permission in IDA once per Pipe. All MCP clients share the temporary decision until that Pipe or database closes.
- Refresh debugger availability on every instance query, fixing unavailable errors after selecting a debugger.
- Allow up to 120 seconds for the first debugger confirmation and operation.

## 更新内容

- Gateway 程序、代码模块、MCP 服务及客户端配置项统一命名为 `ida-mcp`；插件与安装包保留 `ida-agent`。
- 按完整包全新安装，不提供旧名称别名或 MCP 配置自动迁移。
- 每条 Pipe 首次调试请求在 IDA 弹窗授权；全部 MCP 客户端共享临时决定，Pipe 重建或数据库关闭后失效。
- 每次查询实例时刷新调试器状态，修复选择调试器后仍报告不可用的问题。
- 首次调试确认及操作最多等待 120 秒。
