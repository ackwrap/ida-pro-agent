## Changes

- Fix Windows Codex detection when the manager inherits an outdated PATH. Discover common npm/Scoop installations and the desktop app's bundled CLI, use the native executable, and support `IDA_AGENT_CODEX_PATH` for custom installations.
- Add ZCode to the local manager with MCP install/update/removal and optional IDA skill links. Preserve existing settings and active shared MCP servers.
- Keep CLI diagnostics separate from MCP JSON output and hide background CLI windows.
- Fix release publishing after creating a draft by using the creation response directly.

Close IDA and clients using the Gateway before upgrading. Existing provider settings and chat history keep their format.

## 更新内容

- 修复 Windows 管理页继承旧 PATH 时找不到 Codex 的问题，支持常见 npm/Scoop 安装位置及桌面应用自带的 CLI，优先使用原生程序，并支持 `IDA_AGENT_CODEX_PATH` 自定义路径。
- 管理页新增 ZCode，支持 MCP 安装、更新、移除，以及可选的 IDA 技能链接，保留已有设置和正在使用的共享 MCP 服务。
- 分离 CLI 诊断与 MCP JSON 输出，隐藏后台 CLI 窗口。
- 直接使用接口返回的草稿信息，修复首次创建 Release 草稿后的发布失败。

升级前请关闭 IDA 和使用 Gateway 的客户端。已有供应商设置和聊天记录格式保持兼容。
