## 0.4.4

- Use underscore names for all 11 public MCP domain tools in every client, including `ida_instances`, `ida_functions`, and `ida_scripts`.
- Make the fixed tool catalog and disabled tool-list change notifications the default. Existing `--grok` launch arguments remain accepted for compatibility; new configurations no longer need them.
- Update the IDA analysis and IDAPython skills with explicit tool/method routing and complete call examples.
- Correct the stdio smoke verifier to check all 11 public tool names, instance discovery, and clean shutdown.

**Client migration:** Update dotted MCP tool names in scripts and tool allowlists, restart the Gateway, and reconnect the client to refresh its catalog. Method identifiers such as `function.search`, `script.execute`, and `ida.instances.list`, along with their arguments, remain the same.

- 所有客户端的 11 个对外 MCP 领域工具统一使用下划线名称，包括 `ida_instances`、`ida_functions` 和 `ida_scripts`。
- 固定工具目录和关闭工具列表变更通知成为默认行为。旧配置中的 `--grok` 启动参数仍兼容接受，新配置无需此参数。
- 更新 IDA 分析和 IDAPython 技能，明确工具名与方法名的路由关系，并提供完整调用示例。
- 修正 stdio 验证脚本，检查全部 11 个对外工具名、实例发现及正常退出。

**客户端迁移：** 更新脚本及工具允许列表中的点号 MCP 工具名，重启 Gateway 并重新连接客户端以刷新目录。`function.search`、`script.execute`、`ida.instances.list` 等方法标识及其参数保持一致。
