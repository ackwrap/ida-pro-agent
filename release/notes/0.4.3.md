## 0.4.3

- Add macOS Universal 2 builds for Intel and Apple Silicon, with native macOS networking and a scripted DMG installer.
- Add Linux MCP support and distribute the full AI Chat plugin with the Linux x64 package.
- Build and test macOS packages with GitHub-hosted runners; retain the existing installer and command-based launcher.
- Publish Windows, Linux and macOS assets together after all three hosted package jobs and checksum checks succeed; detect compiler concurrency from the available CPUs.

**Linux and macOS versions have not been comprehensively tested. If you encounter a problem, please [submit a bug report](https://github.com/ackwrap/ida-pro-agent/issues), including your OS, CPU architecture, IDA version, reproduction steps, and relevant logs with secrets removed.**

- 新增 macOS Intel / Apple Silicon 通用版本，使用 macOS 原生网络接口，支持脚本化生成 DMG 安装包。
- 新增 Linux MCP 支持，Linux x64 发布包包含完整 AI Chat 插件。
- macOS 安装包由 GitHub 托管 runner 构建和测试，保留现有安装器与命令启动方式。
- 三平台构建和校验全部成功后统一发布 Windows、Linux、macOS 附件，编译并发数按可用 CPU 核心数自动选择。

**Linux 和 macOS 版本尚未经过全面测试。如遇问题，请[提交 Bug / Issue](https://github.com/ackwrap/ida-pro-agent/issues)，附上操作系统、CPU 架构、IDA 版本、复现步骤及已去除密钥等敏感信息的相关日志。**
