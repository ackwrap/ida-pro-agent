## 0.5.5

- Bring the update prompt to the front of IDA when automatic or manual checks detect a newer stable release. The prompt shows the installed and latest versions; **Download Update** opens that version's release page in the default browser.
- Remind automatically once per version during a plugin session. **Later** dismisses the prompt, while manual checks can reopen it from cached release information during the network cooldown. Manual checks also retain their intent when an automatic request is already running.
- Keep the prompt available for retry when opening the browser fails, with a copyable download URL. Handle prompt replacement and parent-window closure safely.
- Add Qt 6.8.2 UI regression coverage for prompt activation, release URLs, dismissal, retries and dialog lifetime. This release also includes the Markdown table selection crash protection from 0.5.4.

**Upgrade:** Close every IDA and IDAT instance, then install the matching plugin and Gateway from the same release package. Settings, chat history and analysis memory are kept. The stable AI UI still requires IDA Professional 9.4 / Qt 6.8.2.

- 自动或手动检查发现较新的正式版本时，在 IDA 前台主动弹窗，显示当前版本和最新版本。点击 **Download Update**，通过默认浏览器打开对应版本的发布下载页。
- 同一插件会话内，每个版本只自动提醒一次；点击 **Later** 可稍后处理。手动检查可使用缓存的新版信息再次打开提示，不受网络检查冷却影响；自动请求进行期间发起的手动检查也会保留提醒意图。
- 浏览器打开失败时保留提示窗口，提供可复制的下载地址并允许重试；安全处理提示窗口替换及父窗口关闭。
- 新增 Qt 6.8.2 UI 回归测试，覆盖前台提醒、版本下载地址、稍后处理、重试和窗口生命周期。本版同时包含 0.5.4 的 Markdown 表格选区崩溃防护。

**升级：** 关闭所有 IDA 与 IDAT 实例，然后从同一发布包安装对应版本的插件和 Gateway。设置、聊天历史与分析记忆会保留。稳定 AI UI 仍要求 IDA Professional 9.4 / Qt 6.8.2。
